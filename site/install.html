Install

One command on macOS and Linux (x86_64 and arm64). The script prints what it will do before doing it, asks before installing anything, and is safe to rerun.

Quick install

curl -fsSL https://smelt.langersword.in/install.sh | sh

Read the script first — it is POSIX sh, set -eu, no sudo, and never pipes into another shell.

Manual install

If you prefer to do it yourself:

# once PyPI publishes (name: smelt-rs)
uv tool install smelt-rs

# until then, from source at a pinned tag
uv tool install git+https://github.com/LangerSword/smelt.git@v0.6-furnace

# then verify
smelt doctor

Nothing is installed silently — the script asks before each install. verify and bench steps never need the network; a model run builds an extension.

Flags

install.sh --dry-run      # print actions, change nothing
install.sh --yes          # assume yes to prompts
install.sh --version X    # install a specific git tag/commit
install.sh --with-tui     # also install the Furnace TUI binary
install.sh --uninstall    # remove smelt

Tested

Untested on macOS. Tested with --dry-run on Linux (x86_64) and sh -n syntax-checked. The platform detection (uname) supports Darwin/arm64 but macOS has not been run.
