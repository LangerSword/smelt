Smelt slow Python into Rust.
Only proven metal ships.

smelt freezes what your function actually does into a differential oracle — 200+ recorded cases, hashed and read-only. A model writes a Rust extension. Code, not the model, checks the answers. Anything that fails or shows no real gain is rejected. The Python stays on as fallback.

the loop

Five steps. Only proven metal ships.

1

select

A pure function of simple types. Impure targets are refused with a hint.

→
2

oracle

Freeze 200+ input/output cases. Hashed, read-only. This is the truth.

→
3

generate

The model writes one Rust function body. It decides nothing else.

→
4

build & verify

Pinned scaffold, static scan, then run against every oracle case. Mismatches feed back, max 3 attempts.

→
5

bench & verdict

Measure the speedup with a confidence interval. Must clear 1.5x lower bound.

The orchestrator is deterministic. Transitions are checkpointed, so runs resume. How it works →

the verdicts

Three outcomes. All honest.

INGOT

Accepted

Verified on every recorded case, and the measured speedup clears the conservative 1.5x lower bound. This is real metal.

SLAG

Rejected

No correct rewrite within the attempt budget, or no meaningful gain. Small functions legitimately fail to beat pyo3 call overhead. A correct result, not an error.

ASH

Refused

The target is impure (I/O, randomness, time, globals) or an unsupported shape. The message names the reason and a refactor hint.
